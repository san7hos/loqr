# loqr

Download or open [`index.html`](index.html) in a browser to create a QR code for text, a URL, or a Wi-Fi network. The page is self-contained and works locally without dependencies or sending data elsewhere.

Wi-Fi passwords are used only while generating the QR code and cleared from the form afterward. Generated codes can be downloaded as SVG files. The generator supports QR Code error-correction level L and content up to 271 UTF-8 bytes.
